MediCare – Hospital Appointment Booking System 🏥

A web-based Hospital Appointment Booking System developed using PHP (OOP), MySQL, Bootstrap 5, and JavaScript. It helps patients book appointments, doctors manage schedules, maintain digital medical records, and manage patient queues.

✨ Key Features

🧑‍⚕️ Patient Module:
Secure registration and login.
Search doctors by specialization.
Book and cancel appointments.
View appointment history.
Access medical records and prescriptions.
Receive system notifications.

🩺 Doctor Module:
Dashboard with appointment statistics.
Manage availability and schedules.
View patient medical history.
Record symptoms, diagnoses, and prescriptions.
Upload prescription files.
Manage live patient queues.

🔐 Security Features:
Object-Oriented PHP architecture.
PDO prepared statements.
bcrypt password hashing.
File type validation and secure file naming.
Role-based access control.

🛠️ Technology Stack:

PHP 8.x :Backend development
PHPmyAdmin: Database 
HTML5, CSS3, JavaScript :Frontend
Bootstrap 5.3 :Responsive UI
jQuery : AJAX operations
Font Awesome 6:Icons
XAMPP :Local server environment

🚀 Installation Guide

Prerequisites: Install XAMPP with PHP 8.0+

Start Apache and MySQL from XAMPP Control Panel.

Copy the project into C:
\xampp\htdocs\hospital_appointment_system.

Create the uploads folder with prescriptions and doctor_profiles subfolders.

Open http://localhost/phpmyadmin.

Create a database named hospital_appointment_system.

Import database/hospital_appointment_system.sql.

Configure database credentials in config/config.php.
